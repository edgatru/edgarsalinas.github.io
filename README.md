# Web de Edgar Salinas — versión idéntica al diseño aprobado

Esta versión utiliza **la imagen final aprobada como la propia interfaz visual**. De esta forma no se interpreta ni rediseña: la web reproduce exactamente el diseño aprobado y coloca zonas de clic transparentes sobre los botones.

### Botones funcionales
- WhatsApp
- Llamar
- Ayuda remota
- Guardar contacto
- Email

### QR
El QR visible se conserva exactamente como aparece en el diseño aprobado. Para que el QR sea realmente escaneable y apunte a la URL pública definitiva, hay que regenerarlo cuando tengamos esa URL. No conviene imprimir el QR actual hasta hacer ese último paso.

### Publicación
Sube `index.html`, `ayuda-remota.html`, `contact.vcf` y `tarjeta-aprobada.png` al mismo directorio de un sitio estático (por ejemplo GitHub Pages).
